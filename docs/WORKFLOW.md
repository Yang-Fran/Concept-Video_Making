# 从教学问题到三分钟影片

## 1. 先明确要连接的概念

本片用一个矩阵 A 把三维空间压成平面，逐步回答维数、列相关、方程可解性和可逆性四问。`main/OUTLINE.md` 负责叙事任务，`main/MATH.md` 统一矩阵、向量与维数，避免画面或字幕各自定义对象。

## 2. 把内容拆到可以实现的层级

`STYLE.md` 规定颜色、布局和视觉语法；`STORYBOARD.md` 分配拍序、认知任务与时间预算；六份 `sections/` 文档进一步列出事件、字幕与检查帧。文档记录了必要的演进背景，部分“初始预算／待确认”是制作时的状态；实际时长以 `film/src/manifest.js` 为准，画面与字幕以实现为准。

## 3. 用确定的帧号实现画面

`manifest.js` 管理拍长，`data.js` 保存字幕与卡片，`sections.js` 调度事件，`stage.js` 和 `ui.js` 分别负责几何与界面。`renderFrame(f)` 从全局帧号计算画面。输入空间、像与零空间的颜色和对象身份在各段中持续保持。

## 4. 先局部审阅，再导出全片

通过 `filmctl qa` 检查关键帧，用 `clip` 看单拍运动，再用 `review` 看章节。数学问题回到参数与口径，叙事问题回到分镜，画面问题回到实现。审阅例子见 `main/film/QA.md`。

## 5. 配音与声音共用画面时间

37 句旁白的帧号与文本在 `tts_timing.json`，实际音频保留在 `film/assets/voice/`。事件谱记录音高、声像、动态与起点；声音围绕表段递减、求和上行和尾声不同去向展开。使用 `soundctl window` 听局部片段，再导出母带与分轨，最后与无声画面混流。

## 6. 将方法迁移到其他主题

先换教学问题与数学参数，再重写总纲和分段事件；复用逐帧渲染、局部审阅和事件谱方法。仍需人检查数学、叙事、画面与听感。几何直觉服务于学习，不能代替一般证明；教学价值也需在实际使用中继续验证。
