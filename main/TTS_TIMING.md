## 1. 结论

- **0% 是主参考**：106.71 s 语音 / 133.47 s 字幕窗（覆盖 80%）；7 处 gap > 1 s，最大 2.15 s；只有 3 处轻微重叠（最大 -0.35 s）。
- **-15% 不能全局用**：125.34 s 语音 / 133.47 s（覆盖 94%）；13 处重叠，最大 -1.07 s。它会把“逐句”变成“抢下一句”。
- 0% 的 20% 空白不是缺陷，正好是纯质地音乐床的空间；先不要为了填满而整体降速。
- 逐句音色/语速一致，不要逐句变 rate；只有明显赶的句子才单独 -5% ~ -10%。
- 3 处轻微重叠：S1-03 / S2-09 / S4-03；优先裁 0.1–0.35 s 尾音，或把下一句推迟 0.1 s，不要加速。

### 3.1 对 hit 的限制

- 全片 **4–5 个 touch 为上限**；T01/T02/T03/T04/T05 里 T03/T05 可删。
- 两个 touch 的间隔不固定：14.8 / 77.8 / 45.0 / 30.4 s（按当前 cue），不要把它们 quantize 到小节。
- 语音期间不敲；只有 T04 在 S4-04 前 1.7 s 的空门里。
- 三次作用（4950 / 5040 / 5140）只用不同形状的 swell，不用三个同样的 hit；否则会变成三拍。
- 不要用 riser / whoosh / 反向 cymbal 做转场；纯质地用 filter / air / sub 的慢变化。

> Audio v2 实际只用了 T01 / T02 / T04 / T05（4 个），T03 未加；另有 4.0 / 42.8 / 72.8 / 81.8 / 165 / 168 / 171.3 的 sub drops。具体以 `film/AUDIO.md` 为准。
