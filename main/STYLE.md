### 布局转换

| 转换 | 默认 | 说明 |
|---|---|---|
| `overlay` | 12–18 f | 舞台不动，UI 卡片浮出 |
| `stage-shift` | 18–24 f | 舞台 viewport / origin 平移；不改 yaw/pitch |
| `dock` | 18–24 f | 四问 L2→L1 右上；当前实现不做动画（CARD01 后直接切到 docked） |
| `dip` | 10–24 f | 到黑；只用于 Act 边界 |
| `fade` | 21–30 f | 交叉淡化 / 片尾黑场 |
| `card-in` | 12 f | L0 章节卡入 |
| `card-out` | 6 f | L0 章节卡出 |
| `shrink` | 30–45 f | 舞台缩成 icon |
| `flatten` | 30–45 f | 材质变平（同场景） |
| `cut` | 0 f | 只用于明确硬切 |

- 布局转换主要是 2D / screen-space，不占“每拍一次相机运动”的预算。
- `stage-shift` 是 viewport 平移，算布局转换，不算相机运动；相机角度 / scale 不变。
- 例外：`shrink` / `flatten` 含相机拉远，算该拍唯一一次相机运动，不再叠加别的相机运动。
- 同一拍里，相机运动和布局转换不要同时做两件大事；一个为主，一个让路。

## 2. 相机与舞台

- 正交相机；z-up；像平面 z=0；世界 1 单位 = 矩阵坐标 1。
- 相机是 `f` 的纯函数；不做物理相机、不做景深。
- 默认 `yaw / pitch = 78 / 30`（S0/S1/S2 L1；合并 B5B6 用 78 / 12；Coda 仍 65 / 30）。
- 每拍最多一次相机运动；30–60 f；默认 `smoothstep`；不 overshoot、不回弹。
- 相机运动在关键揭示前结束；文字 / UI 不随相机。
- `origin` / `scale` 按布局给默认，`sections` 可 ±15% 微调。

| 布局 | viewport | origin（默认） | scale（默认） | 备注 |
|---|---|---|---|---|
| L1 | 1200×852 | (648,474) | 145 px/单位 | 左舞台 |
| L2 | 800×700 | (960,500) | 120 | 中央舞台 |
| L3 | 1200×640 | (960,500) | 120 | ghost 舞台 / 表 |
| L4 | 每格 340×340 | 格中心 | 自动，立方体占 70% | icon 相机，65 / 18 |
| L5 | 888×764 ×2 | (492,478) / (1428,478) | 150 | 双舞台同 scale |
| L0 | — | — | — | 2D 章节卡 |

- 旧的全局 108 px/单位只作参考；L1 用 145、L2 用 120（170 / 150 会让 1200 宽的舞台里像网格溢出），以代码为准。
- 相机 profile 是接口：`layout + origin + scale + yaw/pitch`；`sections` 只调数值，不改语法。

## 3. 颜色与透明度

### 角色语义

| 角色 | 色值 | 含义 | 用在哪 |
|---|---|---|---|
| ink | `#eef2f7` | 定义域 / 中性 / 文字 | 基向量、标签、正文 |
| amber | `#ffb454` | 像 / 秩 / 留下 | 像平面、三列、已答 tracker、像上的 b |
| cyan | `#5fd6f2` | 零空间 / 零度 / 被压掉 | 零空间直线 / 零空间平面、解线 |
| red | `#ff5f74` | 够不到 / 无解 | 像外的 b、无解标记 |
| dim | `#93a4b8` | 次要 | tracker 未答、次要标签 |
| faint | `#4c6178` | 网格 / 辅助线 | 表线、立方体框 |
| bg | `#070a0f` | 底 | 全片背景 |
| q-mint → q-pink | `#96FFC8` → `#FF82AA` | 只给 q 场 | 3D 网格 / ghost；alpha ≤ 0.35 |

- **颜色不是装饰**：每个角色色都必须对应一个语义；不用角色色做纯装饰。
- q 场只做低饱和背景，不进入 UI，不与 amber / cyan 抢。
- tracker 的“已答”用 amber，不用绿色；绿色 / mint 会和 q 场混。

### 透明度

- `α = α对象 × α组 × α拍`；文字 / UI 不乘 3D 的组 alpha。
- 默认：ghost 0.5；q 网格 0.2；像网格 0.38；像平面 0.14；零空间 0.8；tracker idle 0.35；表线 0.03。
- “全部熄灭”= 降到 0.15 ghost，不是删除；全黑只发生在 Act 边界 / 片名 / 定理。
- 高亮：局部脉冲 3–12 f；不做全屏 flash。

- S1 右侧图例：名称组（`像 Im A` / `零空间 Ker A`）右对齐 `x=1680`，秩 / 零度组（`秩 2` / `零度 1`）左对齐 `x=1700`，字号统一 34。
- S1 右侧两行公式（`a3=a1+a2` 与 `(a1,a2,a3)=(Ae1,Ae2,Ae3)`）统一 28 px；a 列 amber、A dim、e ink。
- 屏幕字 vs 字幕：同一句不重复；数字 / 名字上屏，字幕说意义。
- 章节卡不加叙事字幕；片名卡的副题属于卡，不是叙事字幕。
- 不出现：`A(s)`、`det`、“矩阵在变”；不出现没配对字幕的公式。

## 5. 舞台图元

- q 点阵：7×7×7，步长 0.5，343 点，147 线；`q = x + y + z` 染色。
- 图元：点、线、箭头、面、平行四边形、括号、叉、标签。
- 纸面：z=0 的琥珀面；alpha 0.14；纸上网格是 3D 网格的像，不另画直角网格。
- 深度：点 / 线按 depth 排序；半透明面不写 depth；箭头 / 标签最后画。
- 线宽：q 网格 1 px；角色线 2–3 px；箭头 3 px；屏幕空间常数，不随相机缩放。
- 标签：关键标签 36–40 px（像 / 零空间 / 秩 / 零度），注释 24–28 px；始终 upright；屏幕偏移 12 px；同时最多 4 个；出画 / 被遮挡时隐藏；非必要不加引线。
- icon 模式另有一套 LOD，见 §8。

### 状态机

- **Tracker**：hidden（H1）→ full（H2–H3，L2 四角问题卡）→ docked（S1 起；CARD01 后直接切，不演 dock）→ updates（①C1B1 / ②C1B2 / ③④C1B5B6）→ compact（Ch2）→ done（求和）→ off（Coda）。update 6–12 f；dock 18–24 f（当前不用）；compact 12–18 f。
- **Table**：hidden → grid → B → A → C → 0 → sum → theorem ghost。四列分 C2B1–C2B4 四拍出现，每列 20–30 f；和行在 C2B5，15–25 f；不在一拍内砸完。
- **Icon**：stage → flatten → cell。30–45 f。
- **Chapter Card**：in 12 f → hold 36 f → out 6 f = 54 f。
- “全部熄灭”= 0.15 ghost；全黑只由 `dip` 产生。

## 7. 时间语法

| 类别 | 默认 | 用途 |
|---|---|---|
| micro | 3–12 f | 高亮 / pulse |
| enter / exit | 6–12 f | 标签 / UI |
| update | 6–12 f | tracker / matrix card / readout |
| dock | 18–24 f | 四问 L2→L1 |
| camera | 30–60 f | 每拍最多一次 |
| apply | 60–90 f | 塌 / 回看 |
| shrink / flatten | 30–45 f | 舞台 → icon |
| build | 20–30 f / 列 | 表列 |
| hold | 15–45 f | 落点 |
| dip | 10–24 f | 到黑；Act 边界 |
| fade | 21–30 f | 交叉淡化 / 片尾 |
| chapter card | 54 f | 2×54f 保留 |
| subtitle | 3 f in/out | 每行 |

- 缓动：`smoothstep` 默认；相机 / apply 用 ease-in-out；机械扫描才用 linear；不 overshoot、不回弹。
- 落点 hold：每个 beat 的关键揭示后 15–30 f；求和 / 定理后 30–45 f；Coda 问题后 45–60 f。
- S1 reset 不做整屏 crossfade：B1 的 Im 网格 / cyan 线 20 f 淡出，ghost q 空间和基向量同时淡入；琥珀面 / 坐标系不动。
- S1 坍塌用 60 f 的 `apply`：三支基向量各自从 `e_i` morph 到 `A e_i`，不是“基向量淡出、列淡入”。
- 所有时间先给 `initial`（sections v1）；`min / target / max` 只用于没把握的事件，v2 校准后再锁。
- “一镜两结论”禁止：一个 beat 只有一个认知任务；多任务拆拍或加 hold。

## 8. Icon 语法（Ch2）

### 三层

1. **Domain frame**：同一立方体的 12 条边；1 px；ink 0.18；后缘虚线 0.12；无 q 网格。
2. **Image（amber）**：像的维度示意；fill 0.6–0.7 + 1.5 px 边。
3. **Kernel（cyan）**：零空间在同一个立方体里的维度示意；fill 0.25 + 1.5 px 边。

### 四态

| 矩阵 | 琥珀（像） | 青（零空间） |
|---|---|---|
| B | 整个立方体 | 原点一个点 |
| A | 平行四边形 | 一条线 |
| C | 一条线 | 一个面 |
| 0 | 一个点 | 整个立方体 |

- 四个 icon 是**同一个立方体的四种命运**：琥珀维数 3→2→1→0，青维数 0→1→2→3；表还没出数字，rank-nullity 已经可见。
- **Icon 是维度示意，不是字面像**：A 的琥珀形状是 2D 平面符号（平行四边形），不是 A 对整块立方体的字面像（字面是六边形）；B 的整立方体是 3D 满秩符号（字面像通常是平行六面体）。选示意，四个 icon 才能保持同一张图的正反关系。
- 这里的“色块大小”只是视觉提示，不是面积度量；精确的是维数互补：像的维数 + 零空间的维数 = 3。B 和 0 在示意层面是同一张图的正反两面，不是两张不同的图。
- 层序：后缘 → 大形状 → 前缘 → 小形状（线 / 点）最后压上；保证线 / 点不被前缘切掉。
- 立方体前缘要压在琥珀面之上（至少可见），否则面像贴纸，不在空间里。
- 同机位、同 yaw/pitch、同相对 scale；只换矩阵状态。
- 不写标签；矩阵字母放在 cell 外 / 左上角；维度数字在下排。
- 可选：固定 3–5 个 0.3 的 sample point；不要随机白点。
- A 的 icon 就是全片 logo：琥珀面 + 青线；Cover 可直接复用。

### Icon cell

- 388×388；绘图区 340×340；立方体占 70%；24 px padding。
- 矩阵字母 22 px mono，cell 左上；维度文字在下排 30 px，两行“像 3 / 零 0”。
- Transition：`flatten` 30–45 f = 相机拉远 + q 网格淡出 + 标签淡出 + fill 淡入 + 线宽归一化；几何不动，只有材质 / LOD 变。

## 9. 表与追踪器

### Table（L4）

- 四列 × 三行：矩阵 388×250；icon 388×480；和行 388×92；表线 0.03。
- 数字语义：像 amber；零 cyan；和 ink；矩阵字母 mono 22；维度 30；和 40–48。
- 和行：四列 3 3 3 3；上方 amber 细线；求和拍从左到右出现；出现后保持到定理拍。
- 定理拍：表整体 ghost 0.12–0.15；和行高亮；公式从和行上方浮出。
- 表 build 顺序：grid → B cell → A → C → 0；B 的 icon 内容在 B cell 之后 30–40 f 长出；不一次全表砸出来。

### Tracker

- 四张卡；尺寸按状态：full 420×150（L2 四角）、docked 280×140（L1 右上 2×2）、compact 112×80（L4 右上 2×2）、done 同 compact。
- H2 / H3 的 full 就是那四张问题卡本身（同一 420×150 几何），不走 tracker 状态迁移；tracker 第一次出现时已经是 docked。
- 卡面内容按状态：

| 状态 | 尺寸 | 内容 | 字号 |
|---|---:|---|---:|
| full | 420×150 | 完整问题，≤2 行 | 32–36 |
| docked | 280×140 | 符号 + 短名 + 状态点 + token | 22–26 |
| compact | 112×80 | 符号 + 短名 / 状态点；token 可省 | 18–20 |
| done | 112×80 | 符号 + token；amber | 18–20 |

- 符号（用片内图形，不用通用图标）：① 维度括号 / 轴三连；② 平行四边形 + 对角线；③ 平面上的 b / 缺口；④ 双向箭头 / 1:1 立方体。
- Token：① “2+1”；② “共面”；③ “b 在像上”；④ “A 降了一维”。
- Token 飞行：源文字先淡出，token 在同一位置淡入，飞到 tracker 真实槽位；token 在 tracker 之后绘制，始终最高层；落位字号 20，和槽位文字一致，不另起新文本。
- 状态：idle（dim 0.35）→ active（ink + amber pulse）→ answered（amber 边 + token）→ done（dim amber）。不用绿色。
- 更新 6–12 f；dock 18–24 f；compact 12–18 f。
- 具体哪拍点亮：见 `STORYBOARD` 的 tracker schedule，不在 STYLE 定内容。

## 11. 渲染与 QA

- `renderFrame(f)` 纯函数；`window.__ready`；headless Chrome + CDP；帧名 `frame_%04d.png`；`final_frames`；ffmpeg。
- 输出：1920×1080 / 30 fps / 5400 帧 / 180 s。
- QA：每个 beat 取 2–3 个关键帧（事件前 / 事件后 / hold），检查布局、角色色、字幕安全区、tracker / table 状态。
- 改代码必须重渲 QA；QA 是审阅基线。
- 校验：总时长、帧数、关键帧 hash / 目检。

## 13. 不做什么

- 不做 `A(s)`、`det`、“矩阵在变”。
- 不做全屏 flash；高亮只局部。
- 不做没配对字幕的公式。
- 不用角色色做纯装饰。
- 不一个镜头塞两个结论。
- 不用绿色 / mint 做“已答”状态。
- 不在纸上另画直角网格。
- 不保留旧 `00` 的死变体和函数名指针。

## 14. 旧 00 的经验

- 纯函数、q 网格随 `u` 变换、ghost / moving 分层、文字不乘 dim、章节卡只定格式、高亮局部、纸面不画方格、删死变体。
- 这些是原则，不是代码接口；新实现按本文件重新命名。
