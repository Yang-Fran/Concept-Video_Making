# 局部审阅与修改示例

以下方法来自本片的制作迭代，当前脚本和实现以最终 6 节／15 拍为准。

## 怎样检查

1. 根据分段脚本选动作之前、之后及停留阶段的关键帧。
2. 用 `filmctl qa` 查看对象位置、公式、字幕与颜色是否正确。
3. 用 `filmctl clip` 检查运动、转场和阅读时间；必要时用 `review` 查看章节连续性。
4. 修改上游文档与实现后重查对应片段，最后再导出全片。

```powershell
node main/film/tools/filmctl.mjs qa --beat S1/C1B2 --frames 0,120,240
node main/film/tools/filmctl.mjs clip --beat S1/C1B2 --no-burn-in
node main/film/tools/filmctl.mjs review --sections S1
```

## 例一：合并重复的认知任务

中间稿将列向量相关与基向量塌缩分为两拍。修订后，两者在同一段中讲述：先看基向量的落点，再看三列共面与 a3=a1+a2。另将无解与可逆合为 A/B 对照，17 拍收束到 15 拍。

检查时关注：向量的身份是否连续，相关性结论是否来自已经展示的关系，答案进入四问标记前是否给足阅读时间。

## 例二：尾声区分参考网格与迭代结果

A 与 M 的第一次作用都得到平面；后续左侧保持平面，右侧依次变为线、点。淡色参考网格每轮从原始三维空间开始，实色对象则承接上一轮的像。

检查时关注：参考网格与实色结果是否可区分，零空间变化是否对应当前迭代映射，终问是否与画面一致。不能把同秩理解为重复作用必然相同。

## 例三：从连续铺底改为事件谱

连续质地床过厚、低频集中后，声音改为围绕关键事件组织，并增加留白。表段音数减少，求和段使用上行音，尾声以 A 渐轻与 M 掉音对应不同去向。

检查时关注：旁白能否清楚听见，声音事件是否与画面对应，停顿是否有助于阅读。技术校验不替代真人听感判断。
