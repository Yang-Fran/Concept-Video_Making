# MATH — 数学参数表 v1

> 目的：把上屏用的矩阵、向量、零空间 / 像写死，避免渲染时猜。
> 状态：working values；B 的视觉细节可在 v2 校准，但必须保持“满秩、不塌、可逆”。
> 屏幕不出现 `det`、`A(s)`；`J3(0)` 只作内部叫法。

## 1. 主矩阵 A

```
A = [[1, 0, 1],
     [0, 1, 1],
     [0, 0, 0]]

A(x,y,z) = (x+z, y+z, 0)
```

- 像：`z = 0` 平面。
- 零空间：`span(1, 1, −1)`。
- 秩 2 / 零度 1；`A² = A`。
- 三列：`a1=(1,0,0)`、`a2=(0,1,0)`、`a3=(1,1,0)`；`a1+a2−a3=0`。
- 基向量 `e3` 落到 `(1,1,0)`，不是 0；被压成 0 的是零空间方向 `(1,1,−1)`。

## 2. 主向量

| 名称 | 数学值 | 屏幕 | 用在哪 |
|---|---|---|---|
| `b_in` | `(1,1,0)` | `b` | C1B4；在像上 |
| `x_p` | `(1,1,0)` | `x_p` | C1B4；`A x_p = b_in` |
| `b_out` | `(1,1,1)` | `b′` | C1B5B6 抬起；S1 不出现 b′ ghost |
| 解线 | `x = x_p + t(1,1,−1)` | 不写全式，只画 cyan 线 | C1B4 |

- `A b_out = (2,2,0) ≠ b_out`；`b_out` 不在像里，所以 `Ax=b_out` 无解。
- 因为 `b_in` 在像里，`A b_in = b_in`；`b_in` 自己也是解，所以解线穿过 `b_in`。
- 解线方向 = 零空间方向；解线过 `x_p`，与零空间直线平行。

## 3. B（满秩对照）

```
B = [[1.2, −0.3, 0],
     [ 0.3, 1.2, 0],
     [ 0,   0,   1.2]]
```

- 满秩、可逆；像 = 整个空间；零空间 = `{0}`。
- 视觉：旋转 + 缩放；立方体变斜、变大，但**没有塌成低维**。
- 不声明“体积保持”：`det(B) = 1.836`，体积会变；字幕只说“拉伸、转动，但没有塌”。
- `B` 是 working value；v2 可以换成别的满秩矩阵，只要保持“旋转 / 拉伸、不塌、可逆”。
- 矩阵卡 B 的元素按上表；如果换矩阵，卡片同步换。
- C1B5B6 合并段用 `b′ = (1,1,1)` 作 B 的目标；唯一原像 `x = invB(b′) ≈ (0.980, 0.588, 0.833)`。屏幕只写 `b′` / `x`，不写 `invB`。

## 4. C（1+2）

```
C = [[1, 2, 3],
     [1, 2, 3],
     [0, 0, 0]]
```

- 三列共线：`(1,1,0)`、`(2,2,0)`、`(3,3,0)`。
- 像：`span(1,1,0)`。
- 零空间：`x + 2y + 3z = 0` 平面。
- 秩 1 / 零度 2；icon C = 琥珀线 + 青面。

## 5. 0（0+3）

- 零矩阵；像 = `{0}`；零空间 = 整个空间；秩 0 / 零度 3。
- icon 0 = 琥珀点 + 青整立方体。

## 6. Coda 的 J3(0)（内部）

```
J = J3(0) = [[0, 1, 0],
             [0, 0, 1],
             [0, 0, 0]]

J(x,y,z) = (y, z, 0)
```

- 像：`z=0` 平面；零空间：x 轴。
- 秩 2 / 零度 1；与 A 同像、同秩、同零度。
- `J²(x,y,z) = (z,0,0)`：像 = x 轴；零空间 = `z=0` 平面（xy 平面）。
- `J³ = 0`：像 = `{0}`；零空间 = 整个空间。
- 关键对照：A 的零空间 `(1,1,−1)` 横穿像面，J 的零空间 x 轴躺在像面里；所以 A 反复作用停在平面，J 反复作用 2→1→0。
- 屏幕只写“另一个 2+1 矩阵”；不写 `J3(0)`、不写 Jordan、不写“幂零”作为标题。

## 7. 矩阵卡

| 状态 | 内容 | 出现 |
|---|---|---|
| A | 3×3 A 元素；可带 `Ax=b` | S0 H1、S1、S2 C1B4–C1B5B6 |
| A + b | `Ax=b`；b 在像 / b′ 在外 | S2 C1B4 / C1B5B6 |
| B | 3×3 B 元素；`Bx=b` | S2 C1B5B6（B 段） |

- 矩阵卡上的 `b` 与舞台箭头同色同步；C1B4 的 b 在舞台右侧，卡里只放方程。
- A/B/C/0 的 icon 是**维度示意**，不是字面像；见 `STYLE §8`。
