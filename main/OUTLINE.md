| 块 | 拍 | 要完成的事 |
|---|---|---|
| 钩子 | 塌 | 一个矩阵把空间压成一张纸：有的方向留下，有的被压成 0。观众先看见「失去」，但还不知道失去了什么。 |
| 钩子 | 四问 | 依次摆出四个问题：① 这个矩阵，留下几维、压掉几维？② 这三列线性相关吗？③ Ax=b 有解吗？④ A 可逆吗？ |
| 钩子 | 承诺 | 说明这四个问题问的是同一件事：什么留下了，什么被压掉了。 |
| 钩子 | 片名 | 给出片名「秩与零」，副题「秩-零度定理」。 |
| 正章一 · 四问一答 | 命名 + 维数 | 给压扁后的两个对象命名：留下的面叫「像」，被压成 0 的方向叫「零空间」；数出像 2 维、零空间 1 维；像的维数即「秩」，零空间的维数即「零度」。 |
| | 向量 | 三支基向量倒下的地方都在像这个面上；三支列共面，所以线性相关；S1 只讲到“共面”，b′ 留给 S2 的无解。 |
| | 解 | 取像上的一个 b；倒放回看 A 的作用，说明所有落到 b 的 x 构成一条线；这条线和零空间平行；b 在像里时，这就是 Ax=b 的解集。 |
| | 无解 → 可逆 | 把 b′ 抬出像：空间里没有 x 能落到 b′ 上，Ax=b′ 无解；同一个 b′ 换上满秩矩阵 B 后，有唯一原像 x，零空间只剩一个点——B 可逆，A 不可。 |
| 正章二 · 变与不变 | 满秩 | 一个 3×3 满秩矩阵：像 3 维、零空间 0 维；表第一列（实际矩阵数字 + icon），右栏 3/0。 |
| | 秩 2 | 一个秩 2 矩阵：像 2 维、零空间 1 维；表第二列，右栏 2/1。 |
| | 秩 1 | 一个秩 1 矩阵：像 1 维、零空间 2 维；表第三列，右栏 1/2。 |
| | 零 | 零矩阵：像 0 维、零空间 3 维；表第四列，右栏 0/3。 |
| | 求和 | 四列排成表：像的维数 3 2 1 0；零空间的维数 0 1 2 3；和 3 3 3 3。指出和不变。 |
| | 定理 | 总结：秩 + 零空间的维数 = 原来的维数；这就是秩-零度定理。 |
| 尾巴 | 同一个 2+1 | 两套矩阵同秩同像、不同零空间；重复作用后命运不同；提出问题，留给观众思考。 |
