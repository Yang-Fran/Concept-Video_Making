## 4. 数学口径（内部）

- `P_n = im(M^n)`。A：`P_0=全空间`，`P_1=P_2=P_3=z=0 平面`；M：`P_1=z=0`，`P_2=x 轴`，`P_3={0}`。
- ghost 是**原始 3D 空间的副本**，每次只作用一次，所以它总落到 `P_1`；它不会落到 `P_2`、`P_3`。ghost 负责“同一个 A / M 又作用了一次”的节奏。
- solid 是**迭代的像**：第二拍对 P 作用，第三拍对上一拍的像作用。A 在 P 上是恒等（`A e1=e1`，`A e2=e2`，`A(e1+e2)=e1+e2`），所以 P 不再变；M 在 P 上不是恒等（`M(x,y,0)=(y,0,0)`），所以 P→L。
- 列：A 的列为 `e1 / e2 / e1+e2`；M 的列为 `0 / e1 / e2`，第二拍后 `0 / 0 / e1`，第三拍后 `0 / 0 / 0`。列的存亡就是秩。
- 零空间：A 的零空间 `span(1,1,−1)` 横穿 P；M 的零空间 x 轴躺在 P 里；`M²` 的零空间 xy 平面；`M³` 的零空间全空间。
- 嵌套：M 第二拍，solid L 在 ghost P 里；第三拍，solid 点在 ghost P 里。A 第二、三拍，ghost P 与 solid P 重合。
- 屏幕不写 `A²=A` / `M³=0`；让画面证明。`J3(0)` 不上屏，也没有 meta 标签；秩由列的存亡和最终形态读。
